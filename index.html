Products & Open Source

OrbPro [1] & SpaceAware.io [15]

3D orbital visualization engine built on CesiumJS — real-time satellite rendering, sensor field-of-view and viewshed modeling, access and conjunction analysis — and the SSA platform built on it, with AI-driven natural-language globe control over MCP, 608 modeled entity types, and a CCSDS-based REST API.

CesiumJS, WebGL, TypeScript, SaaS

Space Data Network [2][3]

Decentralized peer-to-peer protocol for space data exchange over libp2p, using GossipSub and Kademlia DHT discovery with content-addressed storage, plus a data marketplace with trust-based reputation and encrypted transactions.

Go, libp2p, TypeScript

Space Data Standards [10]

127 FlatBuffer schemas defining a complete type system for space operations: orbital elements, ephemeris, conjunction messages, tracking, catalog management, identity, and marketplace protocols.

FlatBuffers, Schema design

Tudat-WASM [11] & Basilisk-WASM [12]

First WebAssembly ports of TU Delft’s Tudat astrodynamics toolbox and the Basilisk spacecraft simulation framework — high-fidelity propagation, trajectory optimization, and 310+ C++ classes of attitude, power, and sensor dynamics, all running in the browser with no native install.

WASM, C++, Astrodynamics

FlatBuffers WASM [4][5] & FlatSQL [6][7]

Browser port of Google’s FlatBuffers compiler generating code for 13 languages, with zero-copy deserialization at ~250M ops/sec, and a SQL layer over FlatBuffers binary data using SQLite virtual tables and content-addressed indexing at ~580K ops/sec.

WASM, C++, Go, SQLite

HD Wallet WASM [8][9]

Hierarchical deterministic wallet library in WebAssembly — BIP-32/39/44 across 50+ networks with Ed25519, secp256k1, and secp256r1 signing, FIPS 140-3 compliant.

WASM, Rust, Cryptography
